# CircleApp (Jetpack Compose + Kotlin)

CircleApp calculates the area of a circle using the formula:

**Area = π × r²**

## Features
- Built with Jetpack Compose
- Real-time input validation (numbers only)
- Error warning if input is invalid
- Beautiful UI with colors, image, and card layout
- Shows result instantly

## Files in root
- APK: CircleApp.apk
- Screenshots
- Demo video

## Usage
1. Enter the radius (numbers only)
2. Press **Calculate**
3. Result will be displayed below the button
